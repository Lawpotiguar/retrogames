Como carregar
Substitua a variável EJS_gameUrl no script abaixo pelo link direto (raw) da sua ROM hospedada (ex: Netlify). O emulador será carregado automaticamente.
Controles padrão (teclado)
Direcional: ← → ↑ ↓
Pular: Z ou X
Correr/Segurar: Shift
Start / Pause: Enter
Dicas para ghosting
- Se 3 teclas não funcionarem juntas, troque a tecla de correr/pular para outra (ex: X ou C).
- Gamepad USB/Bluetooth é recomendado (sem ghosting).
Problemas comuns
- Tela preta: verifique se o link da ROM é o raw e serve binário.
- Som ausente: verifique volume do navegador e permissões.
